# Feature gaps: workflow, data in and out, reproducibility, collaboration

Lens: getting data in, reshaping it, keeping the work safe and re-runnable,
getting it out to Excel, Word, ELNs, scripts and colleagues. Browser-only.
Checked against code at 4b20864 (2026-11-23). Need ids are from
`docs/research/needs/needs.json` (rank and score in brackets). "ROADMAP:n"
is a line of `docs/ROADMAP.md`.

**Already shipped, so not listed:** the paste report and identifiers kept
as typed (`project/pasteReport.ts`), Import dialog (delimiter, decimal
comma, encoding, transpose, xlsx worksheets: `sheets/common/ImportDialog.tsx`),
recipes (FlowJo, CellProfiler, QuPath, plate grid, qPCR Cq text, Incucyte,
LabChart, multi-read, per-image zips, tidy: `share/recipes/presets.ts:377`),
Reshape wide/long, Convert table to, calculated columns, info constants,
Find, Exclude by ID, sort, insert series, Extract & rearrange with row
filters (`sheets/multivariable/model.ts:149`), manipulations (transform,
normalise, baseline, transpose, prune, fraction of total), templates,
Duplicate family, Apply to new data (`project/replay.ts`), reproduce-on-open
(`project/reproduce.ts`), provenance/History, plain and password share
links (`share/link.ts`, `share/protect.ts`), export bundle
(`share/bundle.ts`), .pzfx export and Prism-to-CSV batch, PowerPoint,
Copy for Word, batch graph export (PNG/SVG/PDF/TIFF), CSV with decimal comma
(`project/exportTable.ts:10`), R/Python snippets per result
(`report/snippets.ts`), checklists, citation, virtualised grid and WebGL
graphs for large data, offline service worker.

## Not feasible or out of scope

- **FCS files and gating** (`flow-gating-provenance`, #126). Reading FCS
  keywords is easy, but statistics need gates, compensation and a gating
  UI, which is a different product (FlowJo, FlowKit). The FlowJo-table
  route stays.
- **Band and lane detection on blot images** (`image-quantification`). Kept
  in Fiji or Image Lab by design (ROADMAP:1076-1078).
- **Live co-editing, synced comments, cloud sync, accounts.** These need a
  server or a signalling relay, which breaks the no-server rule. Files,
  links, W-25 (compare) and W-27 (merge) cover the collaboration that fits.
- **Pushing to an ELN or LIMS through its API** (Benchling, LabArchives).
  Needs a runtime call to a third-party service and credentials. W-34's
  `.eln` file and rich copy are the browser-only route.
- **Opening data from a URL** (Zenodo, OSF, GitHub). A runtime fetch from a
  third party, and it weakens the privacy promise.
- **Bio-Rad .pcrd and LightCycler .ixo.** Encrypted or undocumented binary
  files. Users export RDML instead (W-10).
- **SPSS .sav, SAS, Stata.** No reader in the shipped Pyodide set
  (pyreadstat is a C extension and not in the lock); pandas would add a
  large download for little bench value. Users can export CSV.
- **21 CFR Part 11 audit trail with e-signatures.** Needs identities and
  tamper-proof storage, which means accounts. W-21 and W-24 give the
  lightweight, honest version: what changed and when, with no signatures.
- **Re-creating Prism analyses and graphs from .prism files.** Undocumented;
  OpenDose recomputes instead (ROADMAP:110-111).
- **Running user R code in the page (webR).** Technically client-side, but
  it adds a second runtime of tens of MB and moves away from point-and-click.
  W-32 exports scripts to run elsewhere.
- **Electrophysiology (ABF), mass spectrometry (mzML), sequencing formats.**
  Other domains, with their own tools.
