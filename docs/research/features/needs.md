# Feature gaps from the user-needs research (lens: needs.json + ROADMAP open items)

Sources read: `docs/research/needs/needs.json` (all 84 needs with
`opendose_status` "partial" or "missing", generated 2026-10-09),
`docs/research/needs/IMPROVEMENT-PLAN.md`, and the ROADMAP sections "Open
items (2026-10-04)", "Open items (user research)", "Site validation
follow-ups / Still open", "User-needs catalogue", "Deferred" and "Skipped:
breaks browser-only". Every need was checked again against `engine/opendose/`
and `web/src/` at commit 4b20864 (2026-11-23). 35 of the 84 are now met (see
Appendix A), and the open part of each of the others is a row below. ROADMAP
items that were still open but have weak user-need signal are listed in
Appendix B, not as rows.

"obs" = observations behind the need in needs.json (3,666 in all, 15 venues).
Effort: S = days, M = 1–2 weeks, L = more. "Absent: grepped X" means the
pattern matched nothing in engine/opendose or web/src outside tests.

## 2. Not feasible / out of scope

- **Band and lane detection on the image itself** (`image-quantification`, 10 obs). Feasible in a browser technically, but out of product scope by design (ROADMAP "Skipped: breaks browser-only": image processing stays in ImageJ / Fiji / Image Lab). The hand-off already exists: densitometry reads ImageJ / Image Lab exports (`sheets/assays/densitometry/panels.tsx:240`). N-10 keeps the image linked without processing it.
- **Gating and compensation on FCS files** (`flow-gating-provenance`, research-only flag). Gating belongs to FlowJo / Cytobank; only the gate-path text is in scope (N-11).
- **Instrument files that need a vendor SDK or are encrypted** (for example LabChart's binary `.adicht`; CFX `.pcrd` project files). OpenDose cannot load vendor DLLs, and breaking a vendor's encryption is not acceptable. The text exports, which are already read, cover these instruments. (This is general knowledge about the formats; the repo has no code for them.)
- **Crossing tick marks** (ROADMAP graph-format limits). Plotly has none (`graph/README.md:169`). Building them would mean drawing a custom axis layer, which costs more than it is worth.
- **Do-not-build items** (IMPROVEMENT-PLAN "Do not build"). Observed (post hoc) power, per-dose or per-time-point t tests as the analysis of a curve, automatic outlier deletion, test choice gated on a normality P, data-driven "optimal" survival cut-points, testing fold changes with the control fixed at 1, and linearised kinetics fits as estimators would each make results worse. The current code already offers the alternatives the plan names: the detectable effect (`guide/smallN.ts`), curve comparison, ROUT with a reason, residual plots, the ratio t, and nonlinear Km. `no-post-hoc-power` is therefore met, not open.
- **Any server-side or account feature** (cloud sync, shared team libraries, remote compute for large data). These break the browser-only rule. None of the 84 needs requires one: ROADMAP "Skipped: breaks browser-only" lists none, and this check agrees.
