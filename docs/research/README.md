# User research (October 2026)

Reports gathered by research agents from public sources, used to prioritise
the roadmap in `docs/ROADMAP.md` ("User research" section). Quotes are
from the pages cited; where a page was only visible as a search snippet or
title, the report says so. Reddit was not reachable to the tooling and is
therefore absent.

- `forums-qa-graphpad-faq.md` — Stack Exchange, GraphPad's FAQ index (1,539
  titles counted by theme), Prism 9–11 release notes, licensing pages.
- `alternatives-reviews.md` — review sites and alternative tools.
- `workflows-reporting.md` — concrete bench workflows and journal rules.
- `usability-teaching-trust.md` — habits, first-run, collaboration, trust.
- `hn-github-literature.md` — Hacker News, GitHub issue trackers, methods
  literature, blogs (the re-scoped Reddit study).
